# QA — 학생 사용자 시뮬레이션 어색함 발견 (2026-07-16)

- 방식: Claude in Chrome으로 **실사용자(학생) 관점** 자유 질의, 어색·이상 지점 수집.
- 환경: 로컬 dev(D: 사본, TO-BE 시그니처 경로), `user_id=teststu05`, operia 실서버.
- 목적: 릴리스 전 UX 다듬기 백로그. (설계 변경 아님 — 발견/버그 기록)
- ※ **골든셋(코어50) 정합 검증은 별도 문서** `qa_코어50_대표검증_0716.md` 참조. (성격이 다름 — 자유 시뮬 vs 학습 질의 검증)

## 요약 — 패턴 4가지
- **operia NL 이해 한계**(#2·#5·#8): "뭐/언제/애매입력"을 엉뚱한 집계·기본 스칼라로 해석 → 답이 질문과 어긋남. (학습팀)
- **프론트 문구·라벨 하드코딩**(#1·#5·#6·#7): "O"·"금액"·"지금 사용할 수 있어요"·"100%" 등이 상황에 안 맞게 고정. (프론트, 결정적이라 빠른 수정)
- **테스트 데이터 노출**(#3): 운영 유저 화면에 테스트 가맹점. (데이터/BE)
- **재진입 리셋 공격성**(#9): 느린 응답 대기 중 대화 초기화. (프론트, 임계값 재검토)
