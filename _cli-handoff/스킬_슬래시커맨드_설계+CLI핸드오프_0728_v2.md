## 2. 통합 레지스트리 스키마 (`src/skills.js` — 순수 데이터, 로직 금지)

```js
// 순수 선언형. 나중에 public/skills.json 이관 대비(함수·import 금지).
export const SKILLS = {
  // ── 복합 스킬 ──
  자금보고서: {
    label: '자금보고서', description: '잔액·월추이·사용처·상품을 한 번에',
    icon: '📊', keywords: ['자금','보고서','종합'],
    params: { period: { required: false } },
    summary: '{기간} 동안 {총액}원 썼어요. {최다사용처}에 제일 많이 썼고, 지금 {잔액}원 남았어요.',
    cards: [
      { anchor: '지금 쓸 수 있는 금액 알려줘', card: 'balance',           title: '지금 쓸 수 있는 돈', skipPeriod: true },
      { anchor: '달마다 얼마 썼어',            card: 'report',            title: '달마다 쓴 돈' },  // 월(정정)
      { anchor: '어디에 얼마씩 썼어',          card: 'merchantBreakdown', title: '어디에 썼나' },
      { anchor: '무슨 상품에 돈 많이 썼어',     card: 'merchantBreakdown', title: '무엇에 썼나' },
    ],
  },
  // ── 단일 스킬(기존 8개, card:'auto' = 자동판정·요약문 없음·1호출) ──
  월별내역: {
    label: '월별 사용 내역', description: '내 결제를 월별 보고서로',
    icon: '📅', keywords: ['사용내역','월별','보고서'],
    cards: [ { anchor: '월별 사용 내역 알려줘', card: 'auto', title: null } ],
  },
  // 사용금액·근처가맹점·사용처별·친구비교·온오프라인·주사용처·학교비교 동일 패턴
};
```

규칙: `icon/keywords/command(=키)`는 스킬 최상위(슬래시 메뉴가 소비). `card:'auto'`→cardSignature, 명시타입→forceCard. 단일=요약문 없음·1호출, 복합=요약문+N병렬.

## 3. 실행/렌더 흐름

```
/자금보고서 [지난달]
  → SlashSkillMenu 선택 → 복합 핸들러
  → cards[] 각 anchor(+period 삽입, skipPeriod 슬롯 제외)를 operia에 병렬 호출
       · 각 호출 = ephemeral 세션(앵커별 독립)  · 실패 시 1회 재시도
  → Promise.allSettled → slots[] 조립(성공=데이터, 실패=error)
  → summary 템플릿 조립(빈 슬롯 절 생략, 기간 라벨=queryBreakdown.filters)
  → AI 보고서 말풍선 1개 렌더:
       [요약문] + slot마다 ChartRenderer(forceCard=slot.card, title=slot.title)
```

- 화면 user 메시지 = `/자금보고서`(command). AI = 보고서 말풍선(skillId 태깅).
- 로딩 = 기존 여우 로더. 렌더는 allSettled 후 1회.

## 4. 예외 처리
- 슬롯 실패(에러·빈결과) → 자동 1회 재시도 → 여전히 실패면 그 카드만 빈/에러, 나머지 렌더.
- 강제 카드 타입이 데이터와 불일치 → `table` degrade.
- 병렬이 flaky로 반복 실패 → `VITE_SKILL_PARALLEL=false`로 순차 전환(지연↑, 안정).
