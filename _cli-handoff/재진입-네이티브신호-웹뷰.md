## Goal
지금은 `visibilitychange`(hidden→visible)에서 "숨겨진 시간 ≥ VITE_REENTRY_RESET_MS(기본 10초)"면 랜딩 리셋하는 heuristic을 쓴다(화면 꺼짐에 오작동 가능).
네이티브가 **진짜 재진입 시점에만** `window.eduPayOnReentry()`를 호출하도록 바뀌었으므로:
1. `window.eduPayOnReentry` 훅을 등록해 호출되면 랜딩 리셋.
2. 기존 `visibilitychange` 시간 heuristic 리셋 제거(화면 꺼짐 오작동 근절).

## 네이티브 계약 (확정)
- Flutter가 웹뷰로 되돌아오는 **네비게이션 복귀** 시점에만:
  `webViewController.evaluateJavascript(source: "window.eduPayOnReentry && window.eduPayOnReentry()")`
- **화면 꺼짐/잠금·앱 lifecycle resume 에서는 호출 안 함**(그래서 그 케이스는 이제 리셋 안 됨 = 의도).

## Context
- graphify:
  - `graphify query "App.jsx 웹뷰 재진입 리셋 useEffect: visibilitychange onVisibility·hiddenAtRef·REENTRY_RESET_MS·resetToLanding·onPageShow"`
- 현재(App.jsx, 대략 1177~1197):
  ```
  const hiddenAtRef = useRef(0);
  const REENTRY_RESET_MS = Number(import.meta.env.VITE_REENTRY_RESET_MS) || 10000;
  ...
  const resetToLanding = () => { /* 오버레이 닫고 newChat() 등 */ };
  const onVisibility = () => {
    if (document.visibilityState === "hidden") { hiddenAtRef.current = Date.now(); return; }
    if (document.visibilityState === "visible") {
      const t = hiddenAtRef.current; hiddenAtRef.current = 0;
      if (t && Date.now() - t >= REENTRY_RESET_MS) resetToLanding();
    }
  };
  const onPageShow = (e) => { if (e && e.persisted) resetToLanding(); };
  document.addEventListener("visibilitychange", onVisibility);
  window.addEventListener("pageshow", onPageShow);
  // cleanup: removeEventListener(...)
  ```

## Steps
1. graphify로 위치 확인.
2. **네이티브 신호 훅 등록**(WEBVIEW에서만, 1회): 같은 useEffect 안에서
   ```
   if (WEBVIEW) window.eduPayOnReentry = () => resetToLanding();
   ```
   cleanup에서 해제: `if (WEBVIEW && window.eduPayOnReentry) delete window.eduPayOnReentry;` (또는 등록한 함수와 동일 참조일 때만 제거).
   - 멱등: 여러 번 호출돼도 resetToLanding이 안전하도록(이미 랜딩이면 no-op 수준). resetToLanding 내부 로직은 그대로 재사용.
3. **visibilitychange 시간 heuristic 리셋 제거**: `onVisibility`의 리셋 로직과 `visibilitychange` 리스너 등록/해제를 제거. `hiddenAtRef`·`REENTRY_RESET_MS`가 이것 외에 안 쓰이면 함께 정리(미사용 경고 방지). `VITE_REENTRY_RESET_MS`는 더 이상 안 씀.
   - `onPageShow`(bfcache persisted) 리셋은 유지할지 판단: 유지 권장(진짜 새 로드 복귀 대비). 유지하면 그대로 둠.
4. `resetToLanding`·`newChat`·기타 오버레이/핀 로직 불변.
5. `npm run build` exit 0.
