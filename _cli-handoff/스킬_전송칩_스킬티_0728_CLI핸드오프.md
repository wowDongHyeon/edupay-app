# 스킬 전송 메시지 "스킬 티" — CLI 핸드오프 (2026-07-28)

> 역할: [프론트(edupay-app)]. 입력창은 슬래시 명령이 파란색으로 "스킬 티"가 나는데,
> 전송된 user 메시지 칩은 밋밋해서 스킬로 안 읽힘 → 발신 칩에도 스킬 정체성 부여.
> 스킬 UI 폴리시 배치(스킬_UI폴리시_0728)와 톤 통일(리포트 헤더 배지·입력창 파란색과 일관).
> 커밋·배포 금지(동현). 워킹트리만.

## 확정 스펙 (심문 추천안)
- 대상: **`skillId` 있는 user 메시지 = `SkillChip`** (App.jsx). 일반 말풍선 불변.
- 변경:
  - 스킬 **아이콘 추가**(`SKILLS[command].icon`, 예 📊)를 이름 앞에.
  - **`/명령어` 전체를 accent 블루(#5B4DD6) + 굵게** (지금은 '/'만 파랑) → 입력창 파란 처리와 톤 통일.
  - pill: **accent 테두리(#5B4DD6 계열) + 연보라 배경**으로 또렷하게(현재 흐린 pill 강화).
  - 인자(rest)는 기존대로 pill 왼쪽 평문 유지.
- 일관성: 리포트 상단 "📊 자금보고서 · 스킬" 헤더 배지(스킬_UI폴리시 §1)와 같은 아이콘·색.

```markdown
# Task: 스킬 전송 메시지 칩에 "스킬 티" 부여 (SkillChip 강화)

## Goal
skillId 있는 user 메시지(SkillChip)를 스킬로 명확히 읽히게: 스킬 아이콘 + "/명령어" accent 블루+굵게
+ accent 테두리 pill. 입력창 파란 처리·리포트 헤더 배지와 톤 통일. 일반 말풍선은 불변(회귀 0).

## Context (관련만)
- graphify로 지점만: `graphify query "SkillChip 컴포넌트 skillId user 메시지 칩 렌더 UserBubble Bubble"`
- 스킬 아이콘 출처: `graphify query "SKILLS 레지스트리 icon command skills.js"`
- 건드리면 안 됨: 일반 UserBubble(skillId 없는 메시지), AI 말풍선, 카드 렌더.

## Constraints
- React+Vite+Tailwind. ~/.claude/CLAUDE.md + edupay-app/CLAUDE.md 준수. 커밋 금지(워킹트리).
- 표시 전용 변경 — operia 전송·skillId·라우팅(submitComposer) 로직 불변.
- SkillChip은 App.jsx 내 컴포넌트(집약 파일). 단일 컴포넌트 국소 스타일 변경이라 직접 가능하나, 불확실하면 aegis-dev000 위임.

## Steps
1. `graphify query "SkillChip 컴포넌트 렌더 text command / 파싱"` 로 위치 확인(App.jsx SkillChip).
2. SkillChip에서 command(text의 "/" 다음 첫 토큰)로 `SKILLS[command]` 조회해 `icon` 취득(없으면 아이콘 생략, 안전).
3. 렌더 강화:
   - 아이콘 + "/"+name 을 한 pill 안에. "/"와 name 모두 color #5B4DD6, font-weight 700.
   - pill: background 연보라(예 #EEF0FE~#E0E2FA), border 1px #5B4DD6(또는 #9A8FF0) 로 또렷하게.
   - rest(인자) 있으면 pill 왼쪽에 회색 평문 유지.
4. skillId 없는 메시지는 기존 UserBubble 그대로(분기 유지).

## Definition of Done
- [ ] /자금보고서 전송 시 칩 = 아이콘 + 파란 굵은 "/자금보고서" + accent 테두리 pill(스킬로 명확히 읽힘).
- [ ] 일반 채팅·진입칩 전송 메시지(회색 말풍선) 불변.
- [ ] 리포트 헤더 배지·입력창 파란색과 아이콘·색 톤 일치.
- [ ] npm run build exit 0. 커밋 안 함.

## 검증 환경 / 마무리 (필수)
- dev: http://localhost:5173/?view=webview&user_id=teststu05. .env 원복. dev 서버 종료 금지.
- 검증: build exit + 브라우저로 전송 칩 스크린샷(스킬 vs 일반 말풍선 대비). "완료" 자가보고 금지.
- 완료 보고 끝 3줄(시작 `date +%s`): `⏱ 소요 시간` / `🛠 사용 스킬` / `🤖 사용 에이전트`.
```
