## 변경 1건 — "현재 사용할 수 있는 금액 알려줘"
- **이전(단일 값)**: `SELECT ACCOUNT_BALANCE_AMT AS available_amount FROM V_USER_ASSET …` → 1행 1값.
- **문제**: 프론트 잔액 카드는 **항목별 3행**(바우처(지원금) / 용돈 충전금 / 에듀포인트)으로 렌더 → 단일 값이면 카드가 안 맞고 포인트도 누락.
- **변경(3항목 행)**: 출력 `item, balance, unit` 3행.
  - 바우처(지원금) = 지원금지급(TYPE_CD='S') − 지원금사용(PAY_MEAN_CD='VOUCHER')
  - 용돈 충전금 = 계좌통합잔액(ACCOUNT_BALANCE_AMT) − 바우처(지원금)
  - 에듀포인트 = CURRENT_POINT (단위 'P')
- **⚠️ 확인 요망(오페리아/DB)**: "용돈 충전금" 분리식이 `ACCOUNT_BALANCE_AMT = 충전+지원금 통합` 가정입니다. 통합잔액 구성이 다르면 바우처/용돈 분리식만 조정해 주세요. (출력 컬럼 `item·balance·unit` 3행 형태는 유지)
